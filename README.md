# MapBel — геймифицированный дневник путешествий по Беларуси

Учебный проект: карта открытий с зонами, подтверждение посещений по
геолокации («Я здесь»), достижения, дневник с фотографиями и кооператив
с друзьями (совместные поездки и отметки). MVP покрывает P0+P1 из ТЗ;
планирование поездок — вторично, как и задумано.

Язык интерфейса: русский. Стек: Next.js 16 (App Router, React 19),
TypeScript, Tailwind CSS 4, Prisma 7 + MySQL 8, Auth.js (next-auth v5,
credentials + JWT-сессии), MapLibre GL JS 5 (OpenFreeMap), sharp для фото,
Zod для валидации, Vitest для тестов. Иконки — Lucide, шрифты — Manrope
и Unbounded (Google Fonts, с кириллицей).

## Интерфейс

- **Карта** — на весь экран. На десктопе слева плавающая панель (поиск,
  фильтр категорий, список зон, карточка зоны или места), на телефоне —
  выдвижная шторка снизу. На мелком масштабе видны метки зон с рангом,
  при приближении — значки мест по категориям. Подписи подложки на русском.
- **Место** — шапка в цвете категории, кнопка «Я здесь» с понятными
  состояниями (поиск позиции, проверка, успех с наградами, ошибка с
  повтором), лесенка рангов зоны, логистика, отзывы со звёздами.
- **Дневник** — карточки с обложкой, фильтр по месту и дате, загрузка фото
  перетаскиванием, просмотр фото на весь экран, отметки друзей.
- **Профиль, друзья, поездки, события, редактор** — единая дизайн-система:
  медали рангов, прогресс-бары, аватары, пустые состояния.
- **Предложить место** (`/suggest`) — форма нового места или исправления
  и список своих предложений со статусом проверки.
- **Настройки** — редактирование имени, города и «О себе».
- Страницы 404, ошибки и загрузки. На мобильных — нижняя панель навигации.

## Быстрый старт (чистая машина, без Docker)

Требования: Node.js ≥ 20, MySQL 8 (локальная служба или контейнер).

```bash
# 1. Зависимости
npm install

# 2. Настройка окружения
cp .env.example .env
#   укажите DATABASE_URL (пользователь/пароль вашей MySQL) и сгенерируйте AUTH_SECRET:
#   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# 3. База данных: создайте БД и пользователя (один раз)
#   mysql -u root -p
#   CREATE DATABASE mapbel CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
#   CREATE USER 'mapbel'@'localhost' IDENTIFIED BY 'ваш_пароль';
#   GRANT ALL PRIVILEGES ON mapbel.* TO 'mapbel'@'localhost';
#   FLUSH PRIVILEGES;

# 4. Схема (миграция) и демонстрационные данные
npx prisma migrate deploy       # применяет prisma/migrations
npm run db:seed                 # 7 зон (6 областей + Минск), 58 мест, достижения, события

# 5. Запуск
npm run dev                     # http://localhost:3000
```

Альтернатива шагов 3–4 (если установлен Docker): `docker compose up -d`
поднимает MySQL и MinIO, затем тот же `migrate deploy` + seed.

### Демо-симуляция геопозиции

Серверный режим для разработки: на странице места появляется кнопка
«Демо-позиция (dev)», которая подставляет координаты контрольной точки
места. Включается **только** комбинацией `NODE_ENV != production` и
`DEMO_GEO_ENABLED=true` (обе — серверные переменные; клиентским флагом не
управляется). В production-сборке режим недоступен (AC18).

Браузерная геолокация требует HTTPS (кроме `localhost`) и явного
разрешения пользователя — это стандартное ограничение Geolocation API.
Подмена координат средствами браузера остаётся известным ограничением MVP:
сильная антифрод-защита в ТЗ не требуется.

## Тесты

```bash
npm test            # unit + integration (integration требует БД и seed)
```

- `tests/unit/` — чистая логика: Haversine и радиусы, валидация позиции,
  границы дня/месяца Europe/Minsk, ранги и монотонность, уровни XP.
- `tests/integration/` — транзакция чек-ина против реальной MySQL:
  AC03 (далеко — отказ), AC04 (успех → визит+бронза+XP+ledger),
  AC05 (идемпотентный повтор и конкурентные запросы без дублей),
  AC06 (серебро по порогу), AC07 (низкая точность/устаревшая позиция).

Сквозной сценарий по HTTP (вход → карта → позиция → визит → бронза)
проверялся вручную против dev-сервера: см. раздел «Что проверено» ниже.

## Миграции без теневой БД

`prisma migrate dev` требует права создавать теневую базу. Если пользователь
БД таких прав не имеет (частый случай на локальной Windows-машине):

```bash
# 1. Сгенерировать SQL разницы между текущей БД и схемой
npx prisma migrate diff --from-url "$DATABASE_URL" --to-schema prisma/schema.prisma --script > prisma/migrations/<TS>_name/migration.sql
# 2. Применить и зарегистрировать
npx prisma db execute --file prisma/migrations/<TS>_name/migration.sql
npx prisma migrate resolve --applied <TS>_name
```

Начальная миграция `000000000000_init` в репозитории уже создана этим
способом; `prisma migrate deploy` на чистой БД работает без особых прав.

## Архитектура (кратко)

```
src/
  app/                    страницы App Router и API-роуты
    page.tsx                карта (сервер → MapExplorer → MapLibre)
    places/[slug]/          карточка места + «Я здесь» + отзывы
    diary/                  дневник: список, создание, запись+фото+отметки
    friends/ trips/ events/ profile/ users/[username]/ settings/ editor/
    suggest/                предложение места или исправления
    api/
      places/[id]/checkin/  серверное подтверждение посещения
      diary/[id]/photos/    загрузка фото (multipart, ACL автора)
      photos/[id]/          удаление/подпись фото, tags — отметки друзей
      files/[...key]/       выдача файлов по ACL (приватные — только своим)
      demo/geo/             демо-координаты (только dev, см. выше)
      meta/                 флаги сервера клиенту (demoGeoEnabled, стиль карты)
  lib/
    checkin.ts            транзакция чек-ина: визит+прогресс+ledger+достижения
    achievements.ts       оценка достижений (idempotent, unique userId+code)
    geo.ts dates.ts ranks.ts  чистые функции (unit-тесты)
    catalog.ts profile.ts compare.ts acl.ts  серверные выборки и доступы
    storage.ts photos.ts  локальный диск-драйвер, конвейер фото (sharp, WebP,
                          EXIF удаляется, лимит 10 МБ, сигнатура файла)
    actions/              серверные экшены форм: auth, diary, social, editor, profile
    format.ts cn.ts       даты по Минску, склонения, классы
  components/ui/          дизайн-система: ранги, категории, примитивы
  config/game.ts          ВСЕ настройки игры: XP, радиусы, пороги, лимиты,
                          определения достижений (не размазаны по UI)
prisma/
  schema.prisma           21 модель (раздел 13 ТЗ)
  seed.ts                 воспроизводимые демо-данные
tests/                    unit + integration (Vitest)
```

Подробная схема данных: [docs/DATA-MODEL.md](docs/DATA-MODEL.md).

Ключевые инварианты данных: уникальность пары дружбы, уникальный
`eventKey` в ledger наград (защита от повторного XP), уникальность
`userId+achievementId`, уникальность отзыва `userId+placeId`,
идемпотентность чек-ина (`userId+checkinKey`), не более одного визита
места в календарный день Europe/Minsk (`userId+placeId+visitDay`).
Удаление записи дневника не удаляет визиты; скрытие места не отбирает
выданные награды; каскады настроены только там, где это безопасно.

### Проверка позиции (сервер, раздел 7 ТЗ)

Идентичность — из серверной сессии. Проверяются: нечисловые/невозможные
координаты, отрицательная точность, точность > 100 м, возраст позиции
> 60 сек, «будущие» timestamps. Расстояние — Haversine до контрольной
точки (с возможным override места); радиусы по категориям: памятник/музей/
гастрономия 100 м, замок 200 м, природа/экотропа 300 м, остальное 150 м,
override на месте. Время визита — серверное.

### Совместные поездки (раздел 9 ТЗ)

Совместная отметка: подтверждения минимум 2 принявших приглашение
участников после старта поездки с разницей ≤ 2 часа. Командная награда —
один раз, только участникам с хотя бы одним совместно подтверждённым
местом. Организатор не подтверждает за других; личный прогресс при выходе
не откатывается.

## Данные и лицензии

- Границы зон, координаты мест, события — **демонстрационные**, помечены
  `isDemo`. Это НЕ полный туристический каталог Беларуси. Координаты
  реальных объектов округлены; логистика (часы/цены/контакты) намеренно
  «Не уточнено», чтобы не выдумывать факты.
- Подложка карты — OpenStreetMap через OpenFreeMap: © OpenStreetMap
  contributors (ODbL), условия поставщика тайлов: https://openfreemap.org
  (проверяйте перед продуктивной нагрузкой; есть `MAP_STYLE_URL`).
- Полное покрытие страны зонами — целевое требование и незавершённая
  часть (см. ниже).

## Ограничения и незавершённое

- **Покрытие Беларуси**: 7 зон — 6 областей с контурами настоящих
  административных границ (геометрия снята с открытой административной
  карты страны, `prisma/oblasts.geo.json`) и Минск отдельной зоной по
  городской черте. 58 мест: 30 в Минске, остальные — в своих областях
  (Мир и Гродно, Несвиж, Брест и Пуща, Браслав, новые точки Гомеля и
  Могилёва). Контуры областей соответствуют реальным границам на
  подложке с точностью до нескольких километров.
- **Хранилище файлов**: локальный диск (`FILES_DIR`, по умолчанию
  `./data/files`) вместо S3/MinIO — на машине разработки нет Docker.
  Интерфейс `src/lib/storage.ts` выделен, S3-драйвер подключается без
  изменения остального кода. В docker-compose MinIO присутствует для
  будущей интеграции.
- **База данных**: MySQL 8 вместо предложенного в ТЗ PostgreSQL — на
  машине пользователя уже работала локальная MySQL; Prisma-схема
  переносима, MySQL поддерживает нужные JSON-поля (GeoJSON зон).
- **E2E Playwright** не настроены (unit+integration покрывают критические
  правила; HTTP-сценарий прогнан вручную). Это следующий шаг.
- **Визуальная проверка редизайна** не проводилась: вёрстку на 360 и
  1440 px глазами не просматривали. Работоспособность карты подтверждена
  headless-браузером: канвас создаётся, все 7 пилюль зон и 58 значков
  мест отрисовываются, контуры областей совпадают с границами на
  подложке, ошибок в консоли нет.
- Исправлено падение карты в dev-режиме: React StrictMode перемонтирует
  компоненты с сохранённым состоянием, из-за чего эффекты обращались к
  стилю карты до его загрузки («Style is not done loading»).
- **Editor**: простые защищённые формы (места/зоны/события/предложения/
  модерация), не отдельный admin-продукт — по ТЗ.
- ИИ-проверка фото, бронирования, социальная лента, аудиогиды — вне MVP
  по ТЗ.
